How it works

  1. ☁️

    Amazon CloudFront + S3

    Serves the static app and every portrait from a private bucket via Origin Access Control.

  2. ⚡

    API Gateway + Lambda

    Validates the request and starts an async worker, so there are no servers to manage.

  3. 🧠

    Claude Opus 5.5

    Acts as the art director: invents a fictional character, story and palette, writes the image prompt, and screens unsafe ideas.

  4. 🎨

    Stability AI on Amazon Bedrock

    Stable Image Ultra paints the character in the era and style you chose.

  5. 🎭

    AlphaFace on Amazon SageMaker

    A real-time face swapper that handles different head poses. It runs on a GPU endpoint and places your face into the painting, colour-matched to the brushwork. If no face can be swapped, Stable Image Control Structure repaints your photo instead.

  6. 📺

    Gallery display

    A kiosk screen cycles through the newest portraits and shows a QR code, so visitors can make their own on their phone.
